What's new in this fork

Same classes, same breakpoints, same ~400 lines of plain CSS. Three additions, all opt-in: design tokens, automatic dark mode, and a cascade layer so your own CSS always wins.

Tokens

Every color, spacing value, border radius, font family, the container width, and the grid gutter is now a custom property on :root. Nothing is hard-coded anymore — retune the whole site by changing a handful of variables instead of hunting through the file.

Dark mode

Pages using this stylesheet follow prefers-color-scheme automatically — no markup changes required. To force a mode regardless of OS setting, set data-theme on <html>:

<html data-theme="dark">
<html data-theme="light">
Try it

This page is rendered with the live stylesheet, so the toggle below is switching real tokens in real time.

Overriding a token

Tokens live in @layer skeleton, so any unlayered rule on your own page beats them regardless of selector specificity — no !important needed. To retheme, just redeclare the token after the stylesheet is linked:

<link rel="stylesheet" href="css/skeleton.css">
<style>
  :root {
    --color-primary: #e91e63;
    --border-radius: 2px;
    --container-width: 1100px;
  }
</style>
The grid, unchanged

Still .container > .row > .column/.columns, still .one through .twelve, still .offset-by-*. It's CSS Grid under the hood now instead of floats, but the markup and the rendered widths are identical.
